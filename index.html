01

คำนวณแม่นระดับสตางค์ ทดสอบทุกเคสAccurate to the satang, tested every case

สมองคำนวณเงินแยกออกจากหน้าจอ และผ่านชุดทดสอบมาตรฐานทุกครั้งก่อนปล่อย ครอบคลุมภาษีขั้นบันได เบี้ยขยัน พนักงานรายวัน กะข้ามคืน และการปรับยอดรายคน — เลขผิดแม้สตางค์เดียวคือปล่อยไม่ได้The money engine is isolated from the UI and must pass a full golden-test suite before every release — progressive tax, allowances, daily wage, overnight shifts, per-person adjustments. A single satang off means it does not ship.

02

ตรวจสอบย้อนได้ทุกรายการ แก้ไม่ได้ลับหลังEvery action traceable, nothing changed in the dark

ทุกการลงเวลา อนุมัติ แก้ไข และส่งออกข้อมูล ถูกบันทึกว่าใครทำ เมื่อไร และข้อมูลแต่ละบริษัทถูกแยกขาดที่ระดับฐานข้อมูล ผู้ตรวจสอบตรวจย้อนได้ พนักงานเห็นความจริง ข้อพิพาทจบเพราะบันทึกพูดแทนEvery punch, approval, edit and export is logged with who and when — and each company's data is isolated at the database level. Auditors can trace it, employees see the truth, disputes end.

แยกข้อมูลรายบริษัทPer-tenant isolation

ข้อมูลแต่ละองค์กรถูกแยกขาดที่ระดับฐานข้อมูล (RLS) ยิง API ตรงก็ข้ามบริษัทกันไม่ได้Each organisation's data is isolated at the database level (RLS) — even a direct API call cannot cross tenants.

ปกปิดข้อมูลอ่อนไหวSensitive-field masking

เลขบัตรประชาชนและเลขบัญชีถูกจำกัดสิทธิ์และปกปิดบางส่วนบนหน้าจอตามบทบาทผู้ใช้National ID and bank numbers are access-restricted and masked on screen by role.

สอดคล้อง PDPAPDPA-aligned

ออกแบบตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล มีข้อตกลงประมวลผลข้อมูล (DPA) กับลูกค้าทุกรายDesigned around Thailand's PDPA, with a DPA signed with every customer.

ไม่เก็บข้อมูลสุขภาพNo health data stored

การลาป่วยบันทึกเฉพาะประเภทและจำนวนวัน ระบบไม่เก็บผลวินิจฉัยหรือข้อมูลสุขภาพSick leave stores only the type and number of days — never diagnoses or health data.

maker–checker

คนยื่นคำขอเองอนุมัติเองไม่ได้ หัวหน้าเห็นเฉพาะลูกน้องสายตรง ป้องกันการทุจริตเชิงระบบNo one approves their own request; managers see only direct reports — structural fraud prevention.

เข้ารหัสทั้งเส้นทางEncrypted end to end

รับส่งข้อมูลผ่าน HTTPS ทั้งหมด และการส่งออกไฟล์ที่มีเลขบัตรถูกบันทึกในเส้นทางตรวจสอบทุกครั้งAll traffic over HTTPS, and every export containing ID numbers is recorded in the audit trail.
